# 两层报告体系修改意见记录（2026-10-07）

## 0. 定位

| | 对外简版 / Executive Report | 技术详版 / Technical Report |
|---|---|---|
| 读者 | 普通玩家，1–3 分钟看懂核心结论 | 专业媒体、工程师、评测人员，经得起方法学检查 |
| 角色 | 让人相信结果 | 让专业人士相信结果是怎么得出来的 |
| 规则 | **只能压缩，不能重新扩大结论** | **事实和口径母版** |

两版核心数据一致；VALORANT 定位、绝对措辞、3–9 dB 解释、“识别 / EQ”相关结论需要同步修改。

### 统一母结论（两版都围绕这句话展开）

> 在本次 VALORANT 与 PUBG 真实游戏录音测试中，C3 FPS AI 对人工确认脚步的中位增强为 +8.7 dB，而枪声中位增益仅 +0.2 dB。将固定静态 EQ 调整至相同脚步增强水平后，枪声也会被提升约 +8.8 dB。结果表明，C3 FPS AI 表现出固定 EQ 难以实现的事件选择性增强特征。与此同时，少量与脚步特征相近的安静瞬态声仍可能被同步增强，本次非脚步事件中约 17% 的增益超过 3 dB。

## 二、对外简版（6–7 页）

1. **封面**：标题“C3 FPS AI 声卡脚步增强功能——客观评测报告”；副标题“基于 VALORANT 与 PUBG 真实游戏录音的同源三轨对比测试”；不出现“未适配”。
2. **结论速览（最重要）**：用母结论替换旧“一句话结论”；只突出一张大数字表（FPS AI vs 匹配固定 EQ：脚步 +8.7 / +8.7，枪声 +0.2 / +8.8）；三个标签“脚步更突出｜枪声基本保持｜固定 EQ 难以复制这种选择性”；灰色“边界说明”写出 17%，不隐藏。
3. **实验为什么公平**：一张流程（同一段音频 → 三轨 → 同一声音同一时间点比较 → 人工盲听确认类别）；四个数字（31 段 / 7.7 min / 1620 候选事件 / 348 人工标注）；“主结果仅使用人工确认且无瞬态重叠的事件（170 脚步、72 枪声）”。AST、CLAP、AUC、κ、四轮主动学习等压缩为一句脚注：“标注采用盲听复核，人机协同模型仅辅助扩展；详细质量控制见技术报告。”
4. **核心实验**：标题“同样把脚步提高约 8.7 dB，固定 EQ 会把枪声一起抬高”；左 Raw→FPS AI（脚步 +8.7、枪声 +0.2），右 Raw→匹配固定 EQ（脚步 +8.7、枪声 +8.8）。明确区分：**实际 EQ = 产品预设**；**匹配固定 EQ = 为公平实验额外构造的分析对照**（按 FPS AI 脚步增强曲线构造并调到相同脚步增益的静态 EQ），避免误认为 C3 自带模式。
5. **真实游戏结果**：删除适配 / 泛化逻辑，标题“两款目标游戏中均观察到选择性增强”；表（VALORANT 脚步 +8.0 / 枪声 +0.2；PUBG +11.8 / +0.1）；只解释“幅度不同，但都呈现脚步明显增强、枪声中位变化较小的总体模式”。
6. **更多证据 + 边界**：标题“不仅是音量：FPS AI 对枪声音色结构的改变也明显低于实际 EQ”；突出“≈ 实际 EQ 的 1/6”，1.3 vs 8.1 dB² 放小字；已知边界：约 17% 非脚步瞬态 > 3 dB；集中在远处安静枪声、换弹、部分道具声；脚步附近背景同步抬升；只验证声学处理效果，不等价于证明定位能力提升。
7. **结论**：“本次测试表明，C3 FPS AI 在 VALORANT 与 PUBG 两款目标游戏中均表现出明显的脚步选择性增强：脚步获得显著增益，而响亮枪声整体保持稳定；这一差异无法由具有相同脚步增益的固定静态 EQ 复现。”收尾：“实验支持的是声学处理效果。玩家是否因此更早发现敌人、提升定位准确率，仍需进一步主观听辨实验验证。”

简版不出现：PANNs / 检测器、SEI、模型结构细节、复现说明。

## 三、技术详版（框架保留，口径收紧 + 局部重写）

1. **摘要重写**：删除“只能来自对声音内容的识别”“已适配 PUBG 与未适配 VALORANT”“核心宣称成立”；改为“在控制原始电平后，枪声相较同电平脚步少增强 7.6 dB；采用与 FPS AI 相同脚步增益的匹配静态 EQ 时，该差异接近 0。这表明观察到的选择性不能由固定静态频响解释”；“该趋势在 VALORANT 与 PUBG 两款计划评测游戏中均被观察到”，不写“泛化”。
2. **H1 拆分**：H1a 有效增强（中位数及 95% CI 下限 > 3 dB）；H1b 与宣传 3–9 dB 区间的关系（报告 3–9 / > 9 / < 3 dB 比例：52% / 42% / 6%），结论“增强效果明确成立；实测中位数位于宣传区间上沿，但较多事件的增益高于 9 dB”。
3. **H2 升级为核心发现**：在摘要与 7.1 中作为最核心发现（Footstep +8.7、Gunshot +0.2、同电平差 +7.6、匹配 EQ −0.1 构成完整排他性证据）。假设顺序：H1 脚步增强有效 / H2 不同于固定 EQ 的事件选择性 / H3 非目标保持存在边界 / H4 两款目标游戏及不同条件下结果稳定。
4. **H3 改名**为“非目标声音保持性”：FPS AI 能否在增强脚步的同时较好保持主要非目标声音？结论“部分支持：对响亮枪声保持较好，但对部分安静瞬态、换弹和道具声存在误增强”。
5. **H4** 不再包含“未适配游戏”：表中改为 VALORANT / PUBG；定义改为“在不同目标游戏、事件纯净度、增益计算口径及合理标签噪声扰动下，核心选择性效应方向是否稳定”。
6. **宣传册逐条核验表重写**：状态改为“支持 / 部分支持 / 未覆盖”。3–9 dB 行：“支持‘显著增强’部分；增益分布与 3–9 dB 区间部分重合，中位 +8.7 dB，但 42% 样本超过 9 dB”；“实时识别；不同于传统 EQ”行：“支持存在区别于固定静态 EQ 的事件选择性处理，但本实验不直接推断设备内部识别机制”；游戏一行改为“不同目标游戏上的一致性”：VALORANT +8.0 / PUBG +11.8，枪声 +0.2 / +0.1，“两款目标游戏中趋势一致”。
7. **匹配静态 EQ** 文字收紧：删除“最佳固定 EQ”，改为“构造一个基于 FPS AI 脚步平均频响、并校准到相同脚步中位增益的匹配静态 EQ，作为对固定频响解释的强对照”；保留“对 EQ 一方偏有利，使检验更保守”。
8. **SEI** 保留但降权：注明“SEI 是汇总描述指标；选择性的主要验证仍以同电平脚步–非脚步增益差和匹配 EQ 对照为准”。
9. **频谱 MSE**：保留“总 / 形状”双口径；不说“不破坏音色”，改为“枪声的频谱形状变化显著小于实际 EQ”；主动承认“FPS AI 对脚步本身的频谱形状改变高于实际 EQ，这符合其主动增强目标，但是否影响材质、距离等感知需要主观实验”。
10. **附录 B（机器可识别性）** 保留并强调负结果，开头加“鉴于候选检测器在原始游戏音频上的识别能力不足，本报告不使用机器可检测性作为 FPS AI 效果证据”。

## 七、第三轮意见：对照层级调整（2026-10-07）

原则：报告首要目的是产品宣传与真实产品对比，**主对照应为 C3 自带的实际 EQ**；匹配静态 EQ 降为“用于排除‘固定频响即可解释结果’的机制性辅助对照”，不再作为 FPS AI 的主要竞争对照。

| 层级 | 比较 | 回答的问题 |
|---|---|---|
| 产品主对照 | Raw vs 实际 EQ vs FPS AI | 直接开 C3 的 EQ 与开 FPS AI，到底有什么区别？ |
| 机制性辅助对照 | FPS AI vs 匹配静态 EQ（+ 同电平比较） | 观察到的选择性是否只是固定频响 / 响度差异造成的？ |

关键数字：实际 EQ 脚步 −0.8 dB、枪声 −1.0 dB；FPS AI 脚步 +8.7 dB、枪声 +0.2 dB；匹配静态 EQ 脚步 +8.7 dB、枪声 +8.8 dB。

**更新后的母结论**（详版摘要核心结论，简版据此压缩）：
> 在本次 VALORANT 与 PUBG 真实游戏录音测试中，C3 实际 EQ 未增强脚步（中位 −0.8 dB），而 C3 FPS AI 对人工确认脚步的中位增强为 +8.7 dB，同时枪声中位变化仅 +0.2 dB。进一步将固定静态 EQ 调整至相同脚步增强水平后，枪声也会被提升约 +8.8 dB，表明 FPS AI 的选择性无法由固定静态频响解释。与此同时，少量与脚步特征相近的安静瞬态声仍可能被同步增强，本次非脚步事件中约 17% 的增益超过 3 dB。
